# App Finder

انسٹال شدہ ایپس کو نام سے تلاش کریں، اور نوٹیفکیشن پینل (Quick Settings) میں وائی فائی جیسا بٹن (ٹائل)۔

## ایپ کیا کرتی ہے
- تلاش: ایپ کا نام (یا پیکیج) لکھتے ہی فہرست چھنتی ہے، ہر ایپ کے آئیکن کے ساتھ۔
- ایپ پر ٹیپ: ایپ کھولیں / ہوم اسکرین پر فولڈر تلاش کریں / ایپ کی معلومات۔
- فولڈر تلاش: لانچر کا ڈیٹا پڑھ کر بتاتی ہے کہ آئیکن ڈاک میں ہے، ہوم اسکرین کے کس صفحے پر ہے، یا کس نام کے فولڈر میں؛ پھر "ہوم کھولیں" کا بٹن۔
- نوٹیفکیشن پینل ٹائل "Find App": دبانے سے ایپ کھلتی ہے اور سرچ باکس تیار ہوتا ہے۔ پینل ← ایڈٹ (✎) ← ٹائل کو گھسیٹ کر شامل کریں۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `AppFinder-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں؛ انٹرنیٹ نہیں؛ کوئی خطرناک پرمیشن نہیں۔
- فولڈر کی جگہ پڑھنا لانچر کی اجازت پر منحصر ہے۔ بہت سے لانچرز (خصوصاً نئے اینڈرائیڈ) اسے بلاک کرتے ہیں؛ تب ایپ صاف بتاتی ہے کہ جگہ معلوم نہیں ہو سکی۔
- اینڈرائیڈ کسی ایپ کو ہوم اسکرین کا مخصوص فولڈر خود کھولنے نہیں دیتا؛ ایپ صرف جگہ بتاتی ہے اور ہوم اسکرین پر لے جاتی ہے۔
- ٹائل اینڈرائیڈ 7 (API 24) یا اس سے اوپر پر چلتی ہے۔
